# 视频帧率调整与分段工具

一个基于FFmpeg的Python视频处理工具，支持调整视频帧率并按帧数或时间分段输出。

## ✨ 功能特点

- **帧率调整**：将视频调整为任意目标帧率（如24fps），通过变速方式保留所有原始帧
- **灵活分段**：支持按帧数或按时间两种分段方式
- **高质量编码**：使用x264 CRF 19编码，在保持画质的同时控制文件大小
- **直观GUI界面**：基于tkinter的图形界面，操作简单
- **纯Python实现**：不依赖第三方库，仅需Python标准库和FFmpeg

## 📋 系统要求

- **Python 3.6+**
- **FFmpeg** (包含ffmpeg和ffprobe)
  - [下载FFmpeg](https://ffmpeg.org/download.html)
  - 确保ffmpeg和ffprobe已添加到系统PATH环境变量

### 安装FFmpeg

#### Windows
1. 从 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载
2. 解压到 `C:\ffmpeg`
3. 将 `C:\ffmpeg\bin` 添加到系统PATH

#### macOS
```bash
brew install ffmpeg
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt install ffmpeg
```

### 详细步骤

#### 1. 选择输入文件
- 点击「浏览」按钮选择要处理的视频文件
- 选择后会自动显示视频信息（帧率、总帧数、时长、编码、分辨率）

#### 2. 设置目标帧率
- 在「目标帧率」输入框中输入期望的帧率
- 常用值：24（电影）、30（电视）、60（高帧率）

#### 3. 选择分段方式

**按帧数分段**
- 选择「按帧数」单选按钮

**按时间分段**
- 选择「按时间」单选按钮
- 输入每段的秒数
- 支持小数：如 2.5秒

#### 4. 设置输出目录
- 点击「浏览」选择输出文件夹
- 默认自动设置为输入文件所在目录

## ⚙️ 命令行参数调优

### 核心参数说明

#### 帧率调整参数

```python
# 在 adjust_fps 函数中
'-c:v', 'libx264',      # 视频编码器：H.264
'-crf', '19',           # 质量参数：18-28，越小画质越好
'-preset', 'medium',    # 编码速度：ultrafast, superfast, veryfast, faster, fast, medium, slow, slower, veryslow
'-c:a', 'aac',          # 音频编码器
'-b:a', '192k',         # 音频比特率
'-fps_mode', 'vfr'      # 帧率模式：vfr（可变帧率）
```

#### 分段参数

```python
# 在 split_video 函数中
'-c', 'copy',           # 直接复制流，不重新编码（保持原始质量）
'-f', 'segment',        # 使用分段封装器
'-segment_time', '5',   # 每段时长（秒）
'-reset_timestamps', '1' # 重置时间戳
```

### 调优建议

#### 1. 质量与速度权衡

| 场景 | CRF值 | Preset | 说明 |
|------|-------|--------|------|
| 高质量存档 | 17-18 | slow | 画质优先，文件较大 |
| 日常使用（推荐） | 19-21 | medium | 平衡画质和大小 |
| 快速预览 | 22-23 | fast | 速度优先，画质可接受 |
| 网络分享 | 23-28 | veryfast | 文件小，上传快 |

#### 2. 音频质量调整

```python
'-b:a', '192k'          # 音频比特率
# 可选值：128k, 192k, 256k, 320k
# 192k 在音质和大小间取得良好平衡
```

#### 3. 编码器选择

```python
# 使用H.265 (HEVC) - 更高压缩率
'-c:v', 'libx265'
'-crf', '22'            # H.265的CRF建议值高2-4

# 使用NVENC (NVIDIA GPU加速) - 需NVIDIA显卡
'-c:v', 'h264_nvenc'
'-cq', '19'             # NVENC使用cq参数替代crf
'-preset', 'p7'         # p1-p7，p7画质最好
```

#### 4. 分辨率保持

```python
# 如果想改变分辨率，添加缩放滤镜
'-filter_complex', '[0:v]scale=1920:1080,setpts=PTS*2.5[v]'
```

## 🐛 常见问题

### 1. "找不到FFmpeg"错误
**解决方案**：
- 确认FFmpeg已正确安装
- 在命令行运行 `ffmpeg -version` 测试
- 检查PATH环境变量是否包含FFmpeg的bin目录

### 2. 处理后视频音画不同步
**原因**：音频变速处理不当
**解决方案**：
- 脚本已自动处理音频变速
- 如仍有问题，可尝试在 `adjust_fps` 函数中调整音频处理方式

### 3. 分段文件最后一段过短
**说明**：这是正常现象，最后一段可能不足设定的帧数/时间
**处理**：可以手动删除或合并最后一段

### 4. 处理速度很慢
**优化建议**：
- 降低编码预设值（如使用 `fast` 替代 `medium`）
- 使用GPU加速编码
- 增加CRF值（降低质量要求）

### 5. 帧率调整后画质下降
**优化建议**：
- 降低CRF值（如从19降到17）
- 使用更慢的预设（如 `slower`）
- 考虑使用H.265编码器

## 🔧 技术原理

1. **帧率调整**：使用FFmpeg的 `setpts` 滤镜改变视频播放速度，从而实现帧率转换
   - `setpts=PTS*变速比` 改变视频速度
   - `atempo` 同步调整音频速度
   - 保留所有原始帧，不进行丢帧或插帧

2. **分段处理**：使用FFmpeg的segment封装器
   - 按时间或帧数计算分段点
   - 直接复制流数据，避免重复编码
   - 自动命名和编号
